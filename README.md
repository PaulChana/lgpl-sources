# LGPL sources

Escapement Audio's products ship libraries licensed under the GNU Lesser General Public License.
This repository publishes the complete corresponding source code for each of them.

Each [release](https://github.com/PaulChana/lgpl-sources/releases) is tagged with the product and version it
belongs to, for example `tonepath-0.6.0`, and contains:

- the source archive of every project compiled into the shipped library, exactly as it was built
- the script used to compile the library

## Tonepath

Tonepath ships [libsndfile](https://github.com/libsndfile/libsndfile), with libogg, libvorbis, libFLAC
and Opus compiled into it.

## Licence

libsndfile is licensed under the GNU Lesser General Public License, version 2.1 or later; the full
text is in [LICENSE](LICENSE). Every project in a release keeps its own licence, which is included
in its source archive.
